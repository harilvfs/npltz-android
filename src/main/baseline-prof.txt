# hand-written baseline profile for npltz.
#
# lists the classes and methods on the app's cold start path so art
# pre-compiles them at install time instead of jitting them on the first
# launch. startup path: mainactivity inflate + calendarview + calendar data
# init + the onResume notification/widget/clock refreshes.
#
# rules:
#   Lcom/x/Class;                      every method of the class
#   HSPLcom/x/Class;->name(sig)Ret     startup + hot method
